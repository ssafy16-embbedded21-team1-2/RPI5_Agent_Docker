# RPi5 액티브 쿨러 장착 후 발열 검증

검증일: 2026-11-13 10:15:20~10:20:28 KST.

**결과: 이번 단기 부하 시험에서 팬 자동 제어와 냉각 동작을 확인했다.** 4코어 부하 3분간 최고 65.0°C,
이어진 실제 Qwen 추론 2회에서 최고 69.4°C였고, 전체 측정의 `get_throttled`는 `0x0`이었다.
부하 종료 후 약 1분 뒤 47.95°C로 내려왔다. 장시간 운전의 열평형과 반복 성능은 별도 검증이 필요하다.

사용자가 쿨러 장착을 알렸고 원격에서 팬 회전수를 확인했다. 주변 온도, 케이스·HAT 장착 상태,
쿨러의 물리적 접촉 상태는 직접 확인하지 않았다. Agent의 자원 제한은 호스트 Qwen에는 적용되지 않는다.

## 2. 측정 방법

1. 기존 서비스를 유지한 채 20초간 유휴 상태를 측정했다.
2. 낮은 프로세스 우선순위의 CPU 작업자 4개로 180초간 부하를 발생시켰다.
3. 작업자를 종료한 뒤 Agent `/diagnose`로 `healthy`, `crash_recorded`를 각각 한 번 호출했다.
   `llm_target=local`로 지정했고 실제 Qwen 서버가 응답했다. 진단 입력은 가상 데이터다.
4. 추가 부하를 멈춘 채 60초간 냉각 과정을 측정했다.

온도·팬 RPM/PWM·CPU 사용률·클럭·메모리·스로틀링 비트를 약 1초 간격으로 기록하고,
Agent `/health`를 약 30초마다 확인했다. 80°C 또는 현재 제한 비트가 나타나면 추가 부하를
중단하도록 구성했으며, 이번에는 중단 조건이 발생하지 않았다. CPU 작업자 4개는 모두 정상 종료했다.

냉각 직후에도 팬이 저속으로 회전하는 동작을 관측했다.
CPU 부하 마지막 60개 표본은 60.6~65.0°C여서, 이 시험만으로 열평형에 도달했다고 판단하지 않는다.

이번 호출은 발열 측정 목적이므로 설명 내용의 사실 정확성은 평가하지 않았다.

## 4. 운영 상태와 판정 범위

- 모든 온도 표본에서 `get_throttled=0x0`: 현재 제한과 해당 부팅 이후 기록 비트 모두 관측되지 않았다.
- Agent의 주기적 `/health` 응답은 모두 HTTP 200, 종료 시 컨테이너는 `healthy`였다.
- Qwen 서비스는 종료 시에도 `active`였고 서비스 재시작·재부팅은 수행하지 않았다.
- Agent cgroup의 `oom`, `oom_kill`은 모두 0이었다. 종료 시 메모리는 129.3MiB / 768MiB였다.
- 종료 시 호스트 가용 메모리는 약 5.19GiB, 스왑 사용량은 0이었다.
- `.env`와 `/boot/firmware/config.txt`의 전후 내용은 같았고, 원격 Git 작업 트리도 깨끗했다.
- 팬 설정 변경 없이 자동 회전·속도 조절·부하 종료 후 온도 하강을 확인했다.

[11월 11일 시험](RPi5_SWD_선택_진단_실기기_검증.md)에서는 최고 87.0°C와 스로틀링을 관측했다.
이번에는 최고 69.4°C와 제한 비트 없음이 확인됐다. 다만 부팅·부하·주변 환경이 같은 대조 시험은
아니므로 차이를 쿨러의 정량 성능 개선치로 해석하지 않는다.

이번 결과는 현재 배치에서의 약 5분간 단기 시험 통과다. 장시간 추론, 케이스·HAT를 최종 장착한 상태,
높은 주변 온도에서의 냉각 성능과 응답시간 분포는 남아 있다. 이전에 확인한 Qwen 설명 오류의
해결 여부도 이 결과에 포함하지 않는다.

## 5. 재확인과 원본 기록

```bash
vcgencmd measure_temp
vcgencmd get_throttled
grep . /sys/class/hwmon/hwmon*/name
# 위 출력에서 pwmfan에 해당하는 hwmon 번호를 확인한 뒤 조회
cat /sys/class/hwmon/hwmon2/fan1_input
cat /sys/class/hwmon/hwmon2/pwm1
```

`hwmon2`는 이번 부팅에서 확인한 번호로, 이후에는 달라질 수 있다.
유휴 상태의 팬 정지 여부만으로 고장을 판단하지 않고 온도·PWM·부하 중 회전수를 함께 확인한다.

기록했고, API 키나 `.env` 내용 및 모델 설명 본문은 수록하지 않았다.
